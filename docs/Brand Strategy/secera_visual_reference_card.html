🎯 QUICK RULES TO REMEMBER

CALMNESS OVER URGENCY

  • ✓ Soft tones, generous spacing
  • ✓ Editorial tone, not sales-y
  • ✗ Bright colors, crowded layouts
  • ✗ "BUY NOW" energy

LESS IS MORE

  • ✓ One focal point per layout
  • ✓ Minimal props & styling
  • ✗ Clutter, decorations, badges
  • ✗ Multiple competing messages

PREMIUM ALWAYS

  • ✓ Maroon + warm neutrals
  • ✓ Clean, minimalist layouts
  • ✗ Gold foil, glitter effects
  • ✗ Marketplace aesthetic

CONSISTENCY WINS

  • ✓ Same colors, same fonts, always
  • ✓ Logo rules, size, spacing
  • ✗ One-off designs, random colors
  • ✗ "Just this once" exceptions
When in doubt, ask: Does this feel calm? Does this look premium? Is this consistent with other SECERA touchpoints?
If yes to all three → Go ahead. If no → Redesign.
